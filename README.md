# Jogo da Forca em Python

📋 Sobre o Projeto

Um jogo clássico da forca executado de forma interativa pelo terminal (CLI - Command Line Interface). O jogador tem a missão de adivinhar uma palavra secreta oculta, letra por letra, antes de atingir o limite de 6 erros.

Este projeto foi desenvolvido como uma aplicação prática de lógica de programação, controle de fluxo e manipulação de strings. É ideal para entretenimento rápido e serve como um excelente objeto de estudo de algoritmos básicos.

Público-alvo: Estudantes de ciência da computação, desenvolvedores iniciantes e entusiastas de jogos de lógica e programação.

✨ Funcionalidades Principais

Sorteio Aleatório: Seleção dinâmica da palavra secreta a partir de um banco de palavras interno.

Interface Visual em Texto (ASCII Art): Renderização do estado atual da forca e do boneco a cada erro do jogador.

Validação de Entrada Segura: O sistema rejeita automaticamente números, caracteres especiais, múltiplos caracteres simultâneos e letras já testadas anteriormente.

Feedback em Tempo Real: Acompanhamento instantâneo do progresso das letras descobertas e exibição do histórico.

Sistema de Game Over/Vitória: Condições estritas baseadas no limite clássico de 6 tentativas.

🛠️ Tecnologias Utilizadas

Python 3: Linguagem base utilizada para a construção de toda a lógica do jogo.

Módulo random: Biblioteca nativa (built-in) do Python utilizada para a seleção estocástica das palavras no código.

🚀 Requisitos e Como Executar

Pré-requisitos:

Sistema operacional Windows, macOS ou Linux.

Python 3.x instalado na máquina.

Um terminal de linha de comando (Prompt de Comando, PowerShell, ou terminal do Linux/Mac).

Passo a passo:

Clone este repositório utilizando o Git:

git clone https://github.com/nickolasdasilva39-cmd/NOME-DO-REPOSITORIO.git


Acesse o diretório do projeto:

cd NOME-DO-REPOSITORIO


Execute o script principal via terminal:

python forca.py


(Nota: Em alguns sistemas Linux/macOS, pode ser necessário utilizar o comando python3 forca.py)
